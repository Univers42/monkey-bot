# actors

This directory defines the actors used by the scenarios.

- Each actor describes a functional role in the suite: owner, collaborator, anonymous user, or new user.
- Only actor identity and test intent should live here.
- This directory should not contain navigation logic, assertions, or scenario steps.

In this project, the entry point is [index.ts](/home/settes/cursus/trascendence/monkey-bot/projects/notion-like/actors/index.ts).
